# 運命コアの会話装飾

14 個の独立した常駐正規表現です。JSON をキャラクター正規表現に導入し、世界書の対応 UID の発言規則を manifest.json に記載した専用タグと日本語名に合わせてください。リリスは既存版を保持しています。

助手の表示処理のみ、編集時有効、最大深度 3。各画像は v1.5.9 の固定 URL を使います。旧名・旧 mood 属性・実名引用行は各正規表現の findRegex に明示した範囲だけ互換です。ガウェインと琥珀は同じ画像を使用し、名前を区別します。

読者は注文、人格・外観、手紙、表示、静黙、チェスを保持し、音楽と外部フォント読み込みを削除しています。Stockfish.js 10.0.2 は static/vendor/stockfish-10.0.2 に収録し、チェス利用時に読み込みます。ライセンスとソースへのリンクは同ディレクトリを参照してください。

自動ローダーは置換済みの旧対話 7 件を除外します。3 個の同一候補パッケージは先頭から成功するまで試す既存の予備構成です。常駐ルールは自動削除の対象から保護されます。

現行の 15 開場に存在しない類脳娘、アビゲイル（表・裏・報酬）、奶龍の 5 件も削除しました。候補数は各パッケージ 7 件です。
