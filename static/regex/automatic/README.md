# 自動装飾・日本語版

現行の 15 開場で使う 7 件だけを保持しています。コントロールと装飾の文言は日本語です。Google Fonts の読み込みを廃止し、システムの日本語書体を使います。画像・模様・演出はインライン SVG と CSS で完結し、外部ファイルを要求しません。SVG の xmlns は名前空間識別子であり、ネットワーク通信ではありません。

世界書で指定された英文ルビ、ラテン語の詠唱、フランス語の原詩は保持しています。終幕は [終焉の審判] と旧 [终焉审判] を認識します。旧チャットの中国語ルール名と動的インスタンスは現在の日本語版へ移行します。

- キリン・レヴュー演目：revue-title.json
- キリン・対決宣言（紅と青）：revue-duel.json
- キリン・再生産宣言：revue-reproduction.json
- キリン・終幕演出：revue-finale.json
- ダリアン・幻書詠唱：dalian-chant.json
- エリア・旅の切符：ellia-ticket.json
- 祈りの詩：prayer-poem.json
