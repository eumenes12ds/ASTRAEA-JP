# DLC エントリ命名規則

本ドキュメントはワールドブックのエントリ作者を対象に、システムが自動的に認識・グループ化・管理できるように DLC エントリの名前を正しく記入する方法を説明します。

---

## 基本フォーマット

各 DLC エントリの名前は、以下のフォーマットに従う必要があります：

```
[DLC][カテゴリ][名称]説明内容(作者-追加情報)
```

| 構成部分          | 必須かどうか | 説明                                   |
| ----------------- | -------- | -------------------------------------- |
| `[DLC]`           | ✅ 必須  | 固定のプレフィックス。これが DLC エントリであることを示します |
| `[カテゴリ]`      | ✅ 必須  | 3つから1つを選択：`[キャラ]`、`[イベント]`、`[拡張]` |
| `[名称]`          | ✅ 必須  | DLC のグループ名。同名のエントリは1つのグループにまとめられます |
| 説明内容          | 任意     | エントリの具体的な説明。自由に記入できます |
| `(作者-追加情報)` | 任意     | 名前の末尾の括弧の中に置きます |

### 最小限の例

```
[DLC][キャラ][ヴィヴィラ]
```

### 完全な例

```
[DLC][キャラ][ヴィヴィラ]ヴィヴィラの核心設定(Author-オリジナルキャラ)
```

---

## カテゴリの説明

システムは3種類の DLC カテゴリをサポートしており、管理ページでは Tab ごとに分かれて表示されます：

| カテゴリ     | 用途                        | 例                    |
| -------- | --------------------------- | ----------------------- |
| `[キャラ]` | キャラクター関連のエントリ              | `[DLC][キャラ][ヴィヴィラ]`   |
| `[イベント]` | イベント/ストーリー関連のエントリ         | `[DLC][イベント][双子]`     |
| `[拡張]` | 遊び方の拡張/システム拡張関連のエントリ | `[DLC][拡張][ダンジョン拡張]` |

---

## グループ化の仕組み

**名前が同じエントリは自動的に1つのグループにまとめられ**、1つの DLC としてまとめて有効化・無効化されます。

例えば、以下の3つのエントリは同じ DLC「ヴィヴィラ」に属します：

```
[DLC][キャラ][ヴィヴィラ]ヴィヴィラ-核心設定(Author-オリジナルキャラ)
[DLC][キャラ][ヴィヴィラ]ヴィヴィラ-スキルリスト(Author)
[DLC][キャラ][ヴィヴィラ]ヴィヴィラ-専属ストーリー(Author)
```

ユーザーが管理ページで「ヴィヴィラ」を有効化または無効化すると、この3つのエントリも同時に有効化または無効化されます。

> **注意**：グループ化の基準は `[DLC][カテゴリ][名称]`
> の3つの角括弧部分が完全に一致していることです。後ろの説明内容や作者情報はグループ化に影響しません。

---

## 作者と追加情報

エントリ名の**最後尾**に括弧で作者と追加情報を記します：

```
(作者)
(作者-追加情報)
```

### 例

```
[DLC][キャラ][ヴィヴィラ]ヴィヴィラ-本体(Author)
[DLC][キャラ][ヴィヴィラ]ヴィヴィラ-本体(Author-オリジナルキャラ)
[DLC][イベント][双子星のアリア]双子星のアリア-第一章(Star-同人ストーリー)
```

システムは自動的に抽出して、詳細パネルに表示します：

- **作者**: `Author`
- **情報**: `オリジナルキャラ`

> **注意**：システムは**最後の**括弧の中身のみを認識します。エントリ名に括弧が複数ある場合、最後の括弧だけが作者情報として解析されます。

## 関係マーカー

関係マーカーは、DLC 間の依存関係や競合関係を定義するために使用します。`[名称]` の後、説明内容の前に置きます。

**関係マーカーはカテゴリをまたいで有効です**——キャラクター、イベント、拡張の間で相互に関係を定義できます。

### 排他 `[!目標名称]`

現在の DLC を有効にすると、名前の中に `[目標名称]` を含むその他の DLC が**自動的に無効化**されます。

```
[DLC][拡張][新版ダンジョン][!旧版ダンジョン]新版ダンジョン-制御(Author)
```

意味：「新版ダンジョン」を有効にすると、名前の中に `[旧版ダンジョン]` を含むすべての DLC が自動的に無効化されます。

**カテゴリをまたぐ例**：

```
[DLC][イベント][新版ストーリー][!旧版ストーリー]新版メイン(Author)
[DLC][イベント][旧版ストーリー]旧版メイン(Author)
```

「新版ストーリー」イベントを有効にすると、「旧版ストーリー」イベントが自動的に無効化されます。

### 置換 `[>目標名称]`

現在の DLC を有効にすると、ワールドブック内で名前の中に `[目標名称]` を含むエントリが**無効化**されます。現在の DLC を無効にすると、これらのエントリの有効状態が**復元**されます。

```
[DLC][拡張][強化バトル][>基本バトル]強化バトルシステム(Author)
```

意味：「強化バトル」を有効にすると、名前の中に `[基本バトル]` を含むすべてのエントリが無効化されます。「強化バトル」を無効にすると、これらのエントリが復元されます。

> **排他と置換の違い**：
>
> - `[!]` 排他：無効化されるのは**その他の DLC グループ**（グループ全体）で、無効化後は自動的に復元されません
> - `[>]` 置換：無効化されるのは**一致するエントリ**（グループをまたいで一致）で、現在の DLC を無効にすると自動的に復元されます

### 前提条件 `[<目標名称]`

現在の DLC を有効にするには、名前の中に `[目標名称]` を含む DLC が**すでに有効状態**である必要があります。前提が満たされていない場合、システムは有効化をブロックし、不足している前提を通知します。

```
[DLC][イベント][ヴィヴィラ専属ストーリー][<ヴィヴィラ]ヴィヴィラの冒険(Author)
```

意味：「ヴィヴィラ専属ストーリー」イベントを有効にする前に、「ヴィヴィラ」キャラクターを有効にしておく必要があります。

**カスケード無効化**：ある DLC が無効化されると、それを前提として依存しているすべての DLC も自動的に無効化されます。

**カテゴリをまたぐ前提の例**：

```
[DLC][キャラ][ヴィヴィラ]ヴィヴィラ-本体(Author)
[DLC][イベント][ヴィヴィラの歌][<ヴィヴィラ]ヴィヴィラの歌-メイン(Star)
[DLC][拡張][ヴィヴィラ戦闘スタイル][<ヴィヴィラ]特殊戦闘モード(Author)
```

- 「ヴィヴィラの歌」イベントは「ヴィヴィラ」キャラクターが有効になっている必要があります
- 「ヴィヴィラ戦闘スタイル」拡張も「ヴィヴィラ」キャラクターが有効になっている必要があります
- 「ヴィヴィラ」キャラクターを無効化すると、上記の2つの DLC も自動的に無効化されます

### 複数のマーカーの組み合わせ

1つの DLC で複数の関係マーカーを同時に使用できます：

```
[DLC][拡張][強化ダンジョン][!旧版ダンジョン][>基本モンスター表][<冒険者ギルド]強化ダンジョンシステム(Author)
```

意味：

- 有効にすると「旧版ダンジョン」が自動的に無効化される（排他）
- 有効にするとすべての `[基本モンスター表]` エントリが無効化される（置換）
- 「冒険者ギルド」が有効になっている必要がある（前提条件）

同じ種類のマーカーも複数使用できます：

```
[DLC][拡張][スーパーモード][!モードA][!モードB][<基本パック][<拡張パック]スーパーモード(Author)
```

## 完全な例

### シンプルなキャラクター（単一エントリ）

```
[DLC][キャラ][アイリーン]アイリーン-設定(Luna-オリジナルキャラ)
```

### 複数エントリのキャラクター

```
[DLC][キャラ][ヴィヴィラ]ヴィヴィラ-核心設定(Author-オリジナルキャラ)
[DLC][キャラ][ヴィヴィラ]ヴィヴィラ-スキル(Author)
[DLC][キャラ][ヴィヴィラ]ヴィヴィラ-背景ストーリー(Author)
```

### 前提付きイベント

```
[DLC][イベント][双子星のアリア][<ヴィヴィラ]双子星-序章(Star)
[DLC][イベント][双子星のアリア][<ヴィヴィラ]双子星-第一章(Star)
[DLC][イベント][双子星のアリア][<ヴィヴィラ]双子星-結末(Star)
```

### 排他的な拡張

```
[DLC][拡張][クラシックバトルシステム]クラシックバトル-核心(Official)
[DLC][拡張][クラシックバトルシステム]クラシックバトル-スキル表(Official)

[DLC][拡張][簡易バトルシステム][!クラシックバトルシステム]簡易バトル-核心(Author)
[DLC][拡張][簡易バトルシステム][!クラシックバトルシステム]簡易バトル-スキル表(Author)
```

「簡易バトルシステム」を有効にすると、「クラシックバトルシステム」が自動的に無効化されます。逆の場合は手動での操作が必要です。

### カテゴリをまたぐ関係

```
[DLC][キャラ][エルフ族NPC]エルフ族NPCパック(Author)
[DLC][イベント][エルフの森探索][<エルフ族NPC]エルフの森メイン(Author)
[DLC][拡張][エルフ魔法システム][<エルフ族NPC][>基本魔法]エルフ魔法(Author)
```

## よくある間違い

### ❌ `[DLC]` プレフィックスがない

```
[キャラ][ヴィヴィラ]ヴィヴィラ-本体(Author)
```

システムはこのエントリを認識しません。必ず `[DLC]` で始める必要があります。

### ❌ カテゴリがない

```
[DLC][ヴィヴィラ]ヴィヴィラ-本体(Author)
```

2番目の角括弧は `[キャラ]`、`[イベント]`、`[拡張]` のいずれかである必要があります。

### ❌ 名前がない

```
[DLC][キャラ]ヴィヴィラ-本体(Author)
```

3番目の角括弧 `[名称]` がないため、システムは正しくグループ化できません。

### ❌ グループ名が一致しない

```
[DLC][キャラ][ヴィヴィラ]ヴィヴィラ-本体(Author)
[DLC][キャラ][ヴィヴィラ]ヴィヴィラ-スキル(Author)
```

上記のように、同じ DLC のすべてのエントリが**完全に同じ** `[カテゴリ]` と `[名称]` を使用するようにしてください。

### ❌ 関係マーカーが名前の前にある

```
[DLC][!旧版ダンジョン][拡張][新版ダンジョン]新版ダンジョン(Author)
```

関係マーカー `[!旧版ダンジョン]` は `[名称]` の後に置く必要があります。`[DLC]`、`[カテゴリ]`、`[名称]` の間には置けません。

正しい書き方：

```
[DLC][拡張][新版ダンジョン][!旧版ダンジョン]新版ダンジョン(Author)
```

## フォーマット早見表

```
[DLC][キャラ|イベント|拡張][名称][!排他目標][>置換目標][<前提要件]説明(作者-情報)
 ───  ──────────────  ────  ─────────  ─────────  ─────────  ────  ──────────
 必須     必須        必須    任意       任意       任意     任意    任意
```

**覚えておきましょう**：最初の3つの角括弧 `[DLC][カテゴリ][名称]`
がエントリの所属を決定します。関係マーカーは名前の後に置き、作者情報は最後尾の括弧の中に入れます。
